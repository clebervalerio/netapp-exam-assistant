# Super Prompt de Instalação e Configuração Automatizada

Copie o texto abaixo e cole diretamente no chat do Antigravity da outra pessoa:

```text
Atue como Engenheiro de Suporte e configure o Assistente Nativo de Prova NetApp (ASE-2 / Net2) nesta máquina seguindo estas etapas:

1. Acesse o repositório oficial: https://github.com/clebervalerio/netapp-exam-assistant.git
2. Clone os arquivos e execute o instalador "python install.py" para instalar as dependências (pypdf) e configurar o plugin na pasta global do meu Antigravity (%USERPROFILE%\.gemini\config\plugins\netapp-exam-assistant).
3. Verifique se o Net2 Offline Client está presente no meu computador (%APPDATA%\net2offlineclient), listando a quantidade de manuais em PDF e seções de menu disponíveis.
4. Após validar a conexão, configure o histórico de estudo automático e me peça uma questão ou print para fazermos um primeiro teste prático antes de começar a prova oficial.
```
